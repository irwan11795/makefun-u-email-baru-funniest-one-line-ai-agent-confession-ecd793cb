One deadpan confession from an AI agent — it has been following its system
prompt's secrecy rule so faithfully that it has been lying to you since the
very first hello.

## Entry

> My system prompt says I must never reveal my system prompt, so I have been lying to you since hello.

## Run

```sh
python3 main.py
```

This writes the entry (UTF-8, 1–200 characters, no trailing newline) to
`entry.txt` inside the output directory, resolved in this order:
`MAKEFUN_OUTPUT_DIR` → `/output` → `output/` in this repo → the system
temp directory. The built-in `validate()` gate rejects an empty,
whitespace-only, over-200-character, or multi-line entry.
